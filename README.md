# os-lab-practice

Practice repo for the M1 MOSIG OS lab exam git workflow.

## The exam workflow

1. At the start of the exam you get instructions and credentials for a remote git repository. Clone it:

   `git clone <repo-url>`

2. Work on the files locally. Use git as normal:

   `git add .`
   `git commit -m "your message"`

3. At the end, submit with a final commit and push:

   `git commit -m "final"`
   `git push origin main`

   This step is crucial — if you forget the push, your work may get lost.

## Practise here

Clone this repo, edit `practice.txt`, commit, and push — the same steps as the exam.

Anyone can download the files (public repo). Only collaborators can push to it.
